# Privacy

Last reviewed: 2026-08-23

Navnoor Research is a public static GitHub Pages site. It has no login,
analytics, product telemetry, advertising, third-party script, remote font,
cookie, service worker, or application backend receiving reader input.

The page downloads four fingerprinted same-origin data files needed for local
discovery. Search terms, selected filters, and resolved companies remain in
page memory: they are not added to a URL, browser storage, clipboard, source
request, or telemetry event. Reloading the page clears them.

As with any static website, the hosting platform and network intermediaries may
process ordinary page requests under their own policies. Those asset requests
do not contain the search text because the application never places it in the
URL or request body.

Following a research, publisher, or SEC link leaves Navnoor Research and is
then governed by that destination's privacy policy. Links open with
`noopener noreferrer`.

Do not enter confidential research, personal information, holdings, orders, or
other sensitive information. The product intentionally provides no field for
storing them.
